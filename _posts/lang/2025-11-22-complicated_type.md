포인터가 혼합되어 있는 자료형을 공부하다 보니 머리가 아파져서 공부해 보았고 내가 찾은 방식을 글로 남겨보기로 했다.

## 요약
1. 변수 이름부터 시작
2. clockwise rule로 해석
3. 마지막 base type 만날때까지 진행

## clockwise rule
[원문](https://c-faq.com/decl/spiral.anderson.html)

David Anderson이 제시한 규칙으로 시계방향으로 돌면서 해석하는 트릭이다. 이 때 세 요소가 해석의 대상이 된다.
1. [X] or [] => Array X size of... or Array undefined size of...
2. (type1, type2 ...) => function passing type1 and type2 returning...
3. \* => pointer(s) to...

원문이 영어라 한국어로 바꾸면 좀 의역이 필요하다. 문법 상 순서가 다르니까...

1. [X] or [] => 크기 X의 배열이며 이 배열의 원소 타입은...
2. (type1, type2 ...) => type1, type2, ...를 인자로 받는 함수이며 이 함수의 반환형은...
3. \* => 포인터이며 이 포인터가 가리키는 것은...

함수 인자가 아닌 괄호가 있는 경우 괄호를 먼저 해석한다.

이제 예제를 보자
```
                     +-------+
                     | +-+   |
                     | ^ |   |
                char *str[10];
                 ^   ^   |   |
                 |   +---+   |
                 +-----------+
```

다음과 같이 단계적인 해석이 가능하다.
- str 변수는...
- str 변수는 크기 10의 배열이며 이 배열의 원소 타입은
- str 변수는 크기 10의 배열이며 이 배열의 원소 타입은 포인터이며 이 포인터가 가리키는 것은
- str 변수는 크기 10의 배열이며 이 배열의 원소 타입은 포인터이며 이 포인터가 가리키는 것은 타입 char이다

```
                     +--------------------+
                     | +---+              |
                     | |+-+|              |
                     | |^ ||              |
                char *(*fp)( int, float *);
                 ^   ^ ^  ||              |
                 |   | +--+|              |
                 |   +-----+              |
                 +------------------------+
```
괄호가 있기 때문에 괄호 내부를 먼저 해석한다.
- fp 변수는...
- fp 변수는 포인터이며, 이 포인터가 가리키는 것은...
- fp 변수는 포인터이며, 이 포인터가 가리키는 것은 int, float*를 인자로 받는 함수이며, 이 함수의 반환형은...
- fp 변수는 포인터이며, 이 포인터가 가리키는 것은 int, float*를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은...
- fp 변수는 포인터이며, 이 포인터가 가리키는 것은 int, float*를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은 타입 char이다.

```
          +-----------------------------+
          |                  +---+      |
          |  +---+           |+-+|      |
          |  ^   |           |^ ||      |
    void (*signal(int, void (*fp)(int)))(int);
     ^    ^      |      ^    ^  ||      |
     |    +------+      |    +--+|      |
     |                  +--------+      |
     +----------------------------------+
```
- signal은...
- signal은 int, void (*fp)(int)를 인자로 받는 함수이며 이 함수의 반환형은...

?? 내부에 모르는 fp 변수가 존재한다.

- fp는...
- fp는 포인터이며 이 포인터가 가리키는 것은...
- fp는 포인터이며 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며 이 함수의 반환형은...
- fp는 포인터이며 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며 이 함수의 반환형은 void 타입이다(아무것도 반환하지 않는다).

그럼 간단히 fp는 ...하는 포인터라고 할 수 있겠다. 이제 다시 돌아가서

- signal은 int, 포인터 fp를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은...
- signal은 int, 포인터 fp를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며, 이 함수의 반환형은...
- signal은 int, 포인터 fp를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며, 이 함수의 반환형은 타입 void이다(아무것도 반환하지 않는다).

최종적으로
- signal은 int, fp(fp는 포인터이며 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며 이 함수의 반환형은 void 타입이다(아무것도 반환하지 않는다))를 인자로 받는 함수이며, 이 함수의 반환형은 포인터이며, 이 포인터가 가리키는 것은 int를 인자로 받는 함수이며, 이 함수의 반환형은 타입 void이다(아무것도 반환하지 않는다).
