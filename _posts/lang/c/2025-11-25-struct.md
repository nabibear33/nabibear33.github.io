## 기본적인 것들
### 기본형태
```c
struct Person {
    char name[20];
    int age;
    double height;
};
```
### 멤버 접근
```c
// member reference
p1.age = 20;
p1.height = 182.3;
strcpy(p1.name, "Kim");

// pointer dereference
Person *pp = &p1;
pp->age = 30;
```

### 메모리 배치
멤버 순서대로 메모리에 배치된다고 함.
```c
struct A {
    char c;    // 1 byte
    int i;     // 4 byte
    char d;    // 1 byte
};

// [c][padding][padding][padding][i i i i][d][padding][padding][padding]
```
### 초기화
```c
Person p = {"Lee", 25, 175.2};
Person p = {.age = 30}; // member initialization. added in C99
```


## 포인터가 포함된 경우의 copying 문제
```c
struct student {
    char *name;
    int id;
};

struct student A;
A.name = malloc(20);
strcpy(A.name, "Alice");
A.id = 101;

struct student B = A;
```

위의 경우 ```B.name```과 ```A.name```이 가리키는 대상이 같다. 따라서 A에 할당된 메모리가 해제되면 dangling pointer가 될 수 있다. 직접

## 포인터로 구조체를 정의할 때
```c
struct Node *n;
n->data = 3;   // ❌ segmentation fault

struct Node *n = malloc(sizeof(struct Node));
n->data = 3;  // OK
```
정의되지 않은 상태에서 멤버에 바로 접근하는 것은 불가

## Typedef를 자주 써보자
```typedef```를 사용하여 귀찮음을 줄일 수 있다.
```c
typedef struct {
    int x, y;
} Point;

Point p;  // instead of: struct point p;
```

## 자료 구조에서 중요하게 쓰이는 self-referential structs
Linked list, tree 등에 사용된다.
```c
struct node {
    int data;
    struct node *next;
};
```

## Union

구조체의 멤버가 서로 다른 메모리 공간을 차지하는 것과 다르게 union은 같은 공간을 차지한다.

```c
union Data {
    int i;
    float f;
    char c;
};

sizeof(Data) // 4
```

### 언제쓸까?
- 메모리 절약할 때
```c
union Packet {
    int type;
    char bytes[4];
};
// 프로그래밍 시에는 int로 이해하기 쉽게, 실제 패킷 전달시에는 byte 단위 배열로 보내기
```
- 같은 메모리 주소를 다양한 타입으로 해석하고 싶을 때
```c
union {
    float f;
    uint32_t u;
} v;

v.f = 1.0f;
printf("%x\n", v.u);  // float의 실제 비트 패턴
```

## Bit field

구조체 내에서 멤버가 몇 비트 차지할지 비트 단위로 지정할 수 있다.

```c
struct Flags {
    unsigned int a : 1;  // 1비트
    unsigned int b : 3;  // 3비트
    unsigned int c : 4;  // 4비트
};
```

### 특징
- 메모리 절약
- 포인터를 만들 수 없다

### 어디에 쓰나
- 하드웨어 레지스터 표현에 사용된다.
```c
union Packet {
    unsigned char raw;  // 전체 1바이트
    struct {
        unsigned char type : 4;   // bits 0-3
        unsigned char flags : 3;  // bits 4-6
        unsigned char parity : 1; // bit 7
    } bits;
};
```
