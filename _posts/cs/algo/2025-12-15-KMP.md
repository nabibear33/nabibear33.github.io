## 요약
문자열 패턴 매칭을 선형 복잡도로 해결할 수 있다.


## 아이디어
문자열을 비교할 때, 앞부분부터 비교하게 된다. 정말 단순한 비교 알고리즘은, 모든 문자에 대해 한 칸씩 읽어가며 패턴과 동일한지 파악한다. 하지만 이 경우 $O(string,pattern)$으로 복잡도가 square이다.

다시 돌아가서, "앞부분부터 비교하게 된다"를 조금 더 고민해보면 어떤 조건이 잘 맞으면 중간에 문자가 달라 다음 지점으로 넘어가더라도 다음 시작 지점을 더 효과적으로 잡을 수 있다.

좀 더 구체화해보자. 문자열과 패턴을 비교하다가 어느 틀린 지점이 나왔다고 하자. 그러면 이전까지는 패턴과 문자열이 일치하였다는 뜻이다. 그러면 다시 일치한 부분만 떼어서 보자. 여기서 패턴이 어떤 성질을 만족하면 다음 탐색 지점을 단순히 한 칸 미는 브루트포스 방식이 아닌 jumping이 가능할 수 있다.

그 성질은 패턴의 일치한 부분에 대해 접두/접미사의 최장 공통이 얼마나인지에 대한 정보이다. 만약 접두, 접미사가 공통 부분이 존재한다면 굳이 접두사를 다시 비교할 필요가 없고 jumping을 통해 접두사 다음 인덱스부터 비교하면 계산을 아낄 수 있다.

이를 위해 lps(Longest Proper Prefix which is also Suffix) 배열을 먼저 계산하게 된다. lps는 인덱스까지의 접두/접미사의 최장 공통 부분 길이를 저장한다. 구하는 방법은 접두사는 항상 0에서 시작하니 그곳에 index를 놓고, 비교 문자와 같으면 index와 lps value를 늘려가며 lps 배열에 저장하다가 값이 다르게 되면 초기화한다. 

## 복잡도
pattern m, string n에 대해

브루트포스 : $O(mn)$

KMP : $O(m+n)$, LPS에 m, 매칭에 n


## 헷갈렸던 부분

### lps 계산 시, len = lps[len-1]을 하는 이유
예제

$$ABABCABABA$$

에서 마지막 문자 이전까지 진행하면 lps=[0,0,1,2,0,1,2,3,4,?], len = 4이다

이제 마지막 문자(i = 9) A에 대해 불일치하므로 직전 lps(ABAB)의 lps(AB, 인덱스상으로는 AB'A')로 이동한다. 한 단계 조건을 완화한다고 생각하면 편하다.

여기서 다시 문자열 비교를 진행한다. 인덱스와 길이가 차이가 1만큼 있기 때문에, lps는 len-1을 쓰고 좌변에는 len을 바로 쓰는 것이 자연스럽다.


### jumping 사이에 매칭되는 문자열이 있을 수 있는거 아닌가?
처음에 나는 jumping 자체는 이해를 했는데 jumping으로 건너뛴 부분에 맞는 문자열이 있을 수는 없는지 궁금했다.

만약 이런 경우가 있다고 가정하자.
```
패턴n을 특정 패턴의 이동이라고 정의하자.

문자열 비교 도중 불일치 발생
텍스트: [........일치한 부분........] X ...
패턴0:  [........일치한 부분........] Y

다음 비교는 LPS를 고려하여 jumping 후 인덱스 k부터 시작한다고 하자:
텍스트: [....][.....일치....] X ...
패턴k:        [....일치.....] Y

그런데 k < m 이면서 패턴이 정확히 일치하는 m이 있다고 가정하자. 즉 이전 비교와 jumping 사이에 어떤 일치하는 문자열이 존재한다:
텍스트: [..][.....일치..........]
패턴m:      [....일치...........]

그런데 이 문자열이 존재하려면? 패턴m의 앞부분 또한 lps구조를 갖게 됨을 알 수 있다.
텍스트: [..][.....일치....] X [..일치..]
패턴m:      [....일치.....] X [..일치..]

그리고 그 값은 k보다 크다. 이렇게 되면 lps의 정의에 모순이다. 따라서 이러한 문자열은 존재하지 않고, jumping에 대해 걱정할 필요는 없다.
```

## 의사코드

### LPS
```cpp
//  given pattern
//  let i: index, len: 이전 lps 값
//  while i < pattern size
//      if same p[i] and p[len]
//          len++
//          lps[i] = len
//          i++
//      if different
//          if len > 0, len = lps[len-1]
//          if len == 0
//              lps[i] = 0
//              i++
```

### KMP
```cpp
//  given string, pattern
//  calculate lps vector of pattern
//  i, j = 0 (i : string idx, j : pattern idx)
//  while i < string size
//      if j is pattern size
//          // found
//          add index (i - pattern size) to answer
//          j = lps[j - 1]
//      if same
//          i++, j++
//          continue
//      if different
//          if j > 0, j = lps[j - 1]
//          if j == 0, i++
```
