OpenGL, GLFW, GLAD, GLM 등에서 자주 사용하는 명령어들을 정리해봅시다. 들어가기 앞서, OpenGL은 state machine 방식으로 설계되어, 어떤 전역 상태인 context에 대해 플러그를 꼽았다 뺐다, 스위치를 켰다 껐다 하는 방식으로 함수들이 설계되어 있다는 점을 참고하면 이해하는데에 도움이 될 것 같습니다.

## 공통

```
glGen...()
glBind...()
```
* ```glGen...()```을 통해 오브젝트 이름을 부여하고 (변수 상 ```unsigned int```를 부여)
* ```glBind...()```를 통해 오브젝트를 바인딩
* 바인딩은 간단하게 이후의 동일한 타입 오브젝트에 대한 작업을 이 오브젝트에 대해 수행할게 라는 의미
* Vertex array, buffer, texture, frame buffer, render buffer 등이 각각의 바인딩을 갖는다
* 0은 아무 오브젝트도 바인딩하지 않은 상황을 의미하므로 오브젝트를 사용한 뒤에는 ```glBind...(0)```로 초기화함이 바람직

```cpp
unsigned int VAO[2];
glGenVertexArrays(2, VAO);
```

## Vertex Array Object 관련

```
glGenVertexArrays()
glBindVertexArray()

VAO (ID = 7)
 ├ attrib[0] : enabled/disabled + pointer
 ├ attrib[1] : enabled/disabled + pointer
 ├ attrib[2] : enabled/disabled + pointer
```
* 각 attrib는 position, normal, texcoord를 담당한다
* ```glEnableVertexAttribArray()```는 attrib 번호를 on/off한다
* ```glVertexAttribPointer()```는 attrib에 대한 정보를 제공한다 ex) stride, size, etc.
* attrib 인덱스가 나중에 쉐이더 언어에서 ```layout(location = {attrib index})```와 같이 사용된다.

## Buffer Object 관련

```
glGenBuffers()
glBindBuffer()
glBufferData()
glVertexAttribPointer()
glEnableVertexAttribArray()

ex)
GLuint VBO;
glGenBuffers(1, VBO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, size, data, GL_STATIC_DRAW);
```

* ```glBindBuffer()```는 앞에 타깃을 명시하는데, 이 타깃은 전역 context가 가지고 있는 상태이다. 즉, 전역 context에게 이 오브젝트를 이러한 용도로 쓰겠다는 알림임.
* 이를 통해 ```glBufferData()```에서는 명시된 타깃에 바인딩 된 buffer object를 사용하여 GPU 상에 실제 데이터 값을 주입하게 된다. (CPU -> GPU 데이터 이동)
* 주의 : 인덱스 정보를 저장하는 ```GL_ELEMENT_ARRAY_BUFFER```는 전역 context가 아닌 VAO에 저장되기 때문에, 드로우 콜 시에 이 정보를 저장하고 있어야 한다. 따라서 VBO와는 다르게, VAO가 바인드 되어 있는 한, EBO의 바인드를 먼저 풀어서는 안된다.

```cpp
unsigned int VBO, VAO, EBO;
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glGenBuffers(1, &EBO);
// bind the Vertex Array Object first, then bind and set vertex buffer(s), and then configure vertex attributes(s).
glBindVertexArray(VAO);

glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);

glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);

// note that this is allowed, the call to glVertexAttribPointer registered VBO as the vertex attribute's bound vertex buffer object so afterwards we can safely unbind
glBindBuffer(GL_ARRAY_BUFFER, 0); 

// remember: do NOT unbind the EBO while a VAO is active as the bound element buffer object IS stored in the VAO; keep the EBO bound.
//glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, 0);

// You can unbind the VAO afterwards so other VAO calls won't accidentally modify this VAO, but this rarely happens. Modifying other
// VAOs requires a call to glBindVertexArray anyways so we generally don't unbind VAOs (nor VBOs) when it's not directly necessary.
glBindVertexArray(0); 
```


## Texture 관련
```
glGenTextures()
glBindTexture()
glActiveTexture()
glTexImage2D()
glGenerateMipmap()
glTexParameteri()

// 텍스쳐 생성 단계에서
glGenTextures();
glBindTexture();
glTexImage2D(); // 여기는 stbi 라이브러리 활용
glTexParameteri();
...
glActiveTexture();
glBindTexture();

// 쉐이더 생성 단계에서
...
glUniform1i(glGetUniformLocation(shaderProgram, "texture1"), 0); // 숫자 0이 GL_TEXTURE0와 대응됨

// 렌더링 단계에서
glDrawArrays();

```
* ```glBindTexture```로 텍스쳐 바인딩하고, 실제 데이터를 ```glTexImage2D```로 넣어준다.
* 그 다음 ```glActiveTexture```로 몇번째 유닛을 활성화할지 정하고, 여기에 바인딩했던 텍스쳐를 연결해준다.
* 왜 ```glActiveTexture```에는 ```GL_TEXTURE0```같이 넘버링을 하는데, ```glBindTexture```에서는 타켓 ```GL_TEXTURE_2D```만 지정할까? : 멀티텍스쳐링을 위해 여러 개의 텍스쳐 유닛(```GL_TEXTURE0 + i```, diffuse, normal, roughness 등...)을 필요로 할 수 있기 때문이다.
* 이 유닛 번호는 나중에 ```glUniform1i```을 이용해 쉐이더의 샘플러 파라미터 이름으로 전달된다.


## Frame Buffer 관련
```
glGenFramebuffers()
glBindFramebuffer()
glFramebufferTexture2D()
glFramebufferRenderbuffer()
```
* 언제 쓸까
   - 추가적인 후처리할 때 (blur, bloom, tone mapping ...)
   - shadow mapping 할 때
   - reflection / refraction 할 때
   - 미니맵 표시
   - 객체 picking
   - deffered shading
   - ssao
   - anti aliasing(msaa)
   - 여러 쉐이더 적용할 때 (pingpong 해가면서 rendering)

```cpp
// fbo_width and fbo_height are the desired width and height of the FBO.
// For Opengl <= 4.4 or if the GL_ARB_texture_non_power_of_two extension
// is present, fbo_width and fbo_height can be values other than 2^n for
// some integer n.

// Build the texture that will serve as the color attachment for the framebuffer.
GLuint texture_map;
glGenTextures(1, &texture_map);
glBindTexture(GL_TEXTURE_2D, texture_map);

glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_BORDER);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_BORDER);

glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA, fbo_width, fbo_height, 0, GL_RGBA, GL_UNSIGNED_BYTE, NULL);

glBindTexture(GL_TEXTURE_2D, 0);

// Build the texture that will serve as the depth attachment for the framebuffer.
GLuint depth_texture;
glGenTextures(1, &depth_texture);
glBindTexture(GL_TEXTURE_2D, depth_texture);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_NEAREST);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_NEAREST);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_S, GL_CLAMP_TO_EDGE);
glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_WRAP_T, GL_CLAMP_TO_EDGE);
glTexImage2D(GL_TEXTURE_2D, 0, GL_DEPTH_COMPONENT, fbo_width, fbo_height, 0, GL_DEPTH_COMPONENT, GL_UNSIGNED_BYTE, NULL);
glBindTexture(GL_TEXTURE_2D, 0);

// Build the framebuffer.
GLuint framebuffer;
glGenFramebuffers(1, &framebuffer);
glBindFramebuffer(GL_FRAMEBUFFER, (GLuint)framebuffer);
glFramebufferTexture2D(GL_FRAMEBUFFER, GL_COLOR_ATTACHMENT0, GL_TEXTURE_2D, texture_map, 0);
glFramebufferTexture2D(GL_FRAMEBUFFER, GL_DEPTH_ATTACHMENT, GL_TEXTURE_2D, depth_texture, 0);

GLenum status = glCheckFramebufferStatus(GL_FRAMEBUFFER);
if (status != GL_FRAMEBUFFER_COMPLETE)
    // Error

glBindFramebuffer(GL_FRAMEBUFFER, 0);
```

## Render Buffer 관련
```
glGenRenderbuffers()
glBindRenderbuffer()
glRenderbufferStorage() // glTexImage2D와 비슷한 느낌
```
* fragement shader를 통과한 뒤 detph test가 이루어지는데, 이는 기본적으로 depth buffer에 있는 값을 비교하여 진행된다.
* 기본 프레임버퍼 (유닛 0)에는 depth buffer가 기본적으로 존재하지만, 만약 custom frame buffer를 사용하는 경우에는 직접 depth buffer를 설정해 주어야 한다.
* render buffer는 sampling이 불가능하다. sampler2D 등으로 fragment shader에서 사용하는 texture와는 차이를 보이는데, 좌표 보간, mipmap 처리 등의 과정이 생략되기 때문에 빠르게 연산할 수 있다는 장점이 있다
* 단, 쉐이더에서는 직접 조작하는 것이 불가능하다.
