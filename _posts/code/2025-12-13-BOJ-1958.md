## 문제 한줄요약

lcs(the longest common sequence)를 n차원으로 확장할 수 있다.


## 문제
문자열과 놀기를 세상에서 제일 좋아하는 영식이는 오늘도 문자열 2개의 LCS(Longest Common Subsequence)를 구하고 있었다. 어느 날 영식이는 조교들이 문자열 3개의 LCS를 구하는 것을 보았다. 영식이도 도전해 보았지만 실패하고 말았다.

이제 우리가 할 일은 다음과 같다. 영식이를 도와서 문자열 3개의 LCS를 구하는 프로그램을 작성하라.

첫 줄에는 첫 번째 문자열이, 둘째 줄에는 두 번째 문자열이, 셋째 줄에는 세 번째 문자열이 주어진다. 각 문자열은 알파벳 소문자로 이루어져 있고, 길이는 100보다 작거나 같다.

첫 줄에 첫 번째 문자열과 두 번째 문자열과 세 번째 문자열의 LCS의 길이를 출력한다.



## 아이디어
먼저 2개의 lcs를 구하는 과정을 생각해 보자. 빈 문자열과의 비교는 항상 lcs가 빈 문자열이므로 0으로 두도록 하고 index 0인 행/열을 이 값으로 채운다. 이제 일반화를 위해 두 가지 경우를 생각해 보자
1. 두 문자가 같은 경우

    이 경우는 lcs가 1만큼 증가하는 경우이다. 그런데 어떤 값에 1을 더하는지에 대해 생각할 필요가 있다. 좌측 대각선 위의 값을 가져오게 된다. 나는 처음에 위, 좌측 값중 큰 값을 가져오면 된다고 생각했는데 아니었다. 반례로 'A', 'AA'에서 각 첫, 두번째 문자 비교시를 생각해 볼 수 있다.

2. 두 문자가 다른 경우
    
    이 경우는 lcs가 증가하지 않으므로 이전의 결과를 그대로 가져오게 된다. 이번에도 어떤 값을 가져올지에 대해 생각해 보면 위, 좌측 값중 큰 값을 가져오게 된다.

이제 n차원으로 확장해 보자. n-dim vector를 생성하여 동일하게 dp를 구성할 수 있다. 모든 값이 같다면 -1 index에서 +1을 해주고, 그렇지 않다면 인접 index에서 가장 큰 값을 가져온다.


```cpp
//  given n strings
//  assign n-dim vector with 0 padding at first index(it means empty string)
//  for all index
//      if all char of strings same
//          dp[a1][a2][a3][..] = dp[a1-1][a2-1][a3-1][..] + 1
//      else
//          dp[a1][a2][a3][..] = max(adjecent dp elements)

```

## 최종

```cpp
#include <bits/stdc++.h>
#define DEBUG
using namespace std;


int lcs_3d(string &sa, string &sb, string &sc) {
    int a = sa.size() + 1, b = sb.size() + 1, c = sc.size() + 1;
    vector<vector<vector<int>>> dp(a, vector<vector<int>>(b, vector<int>(c, 0)));
    for(int i = 1; i < a; i++) {
        for(int j = 1; j < b; j++) {
            for(int k = 1; k < c; k++) {
                if((sa[i-1] == sb[j-1]) && (sb[j-1] == sc[k-1]) && (sc[k-1] == sa[i-1])) dp[i][j][k] = dp[i-1][j-1][k-1] + 1;
                else dp[i][j][k] = max(max(dp[i-1][j][k], dp[i][j-1][k]), dp[i][j][k-1]);
            }
        }
    }

    return dp[a-1][b-1][c-1];
}

int main() {
    string s1, s2, s3;
    cin >> s1 >> s2 >> s3;

    cout << lcs_3d(s1, s2, s3);

    return 0;
}
```
