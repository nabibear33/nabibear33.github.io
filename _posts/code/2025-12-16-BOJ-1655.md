## 문제 한줄요약

우선순위 큐를 이용하여 중앙값 구하기를 $O(N\log N)$으로 해결할 수 있다.


## 문제
백준이는 동생에게 "가운데를 말해요" 게임을 가르쳐주고 있다. 백준이가 정수를 하나씩 외칠때마다 동생은 지금까지 백준이가 말한 수 중에서 중간값을 말해야 한다. 만약, 그동안 백준이가 외친 수의 개수가 짝수개라면 중간에 있는 두 수 중에서 작은 수를 말해야 한다.

예를 들어 백준이가 동생에게 1, 5, 2, 10, -99, 7, 5를 순서대로 외쳤다고 하면, 동생은 1, 1, 2, 2, 2, 2, 5를 차례대로 말해야 한다. 백준이가 외치는 수가 주어졌을 때, 동생이 말해야 하는 수를 구하는 프로그램을 작성하시오.

첫째 줄에는 백준이가 외치는 정수의 개수 N이 주어진다. N은 1보다 크거나 같고, 100,000보다 작거나 같은 자연수이다. 그 다음 N줄에 걸쳐서 백준이가 외치는 정수가 차례대로 주어진다. 정수는 -10,000보다 크거나 같고, 10,000보다 작거나 같다.

한 줄에 하나씩 N줄에 걸쳐 백준이의 동생이 말해야 하는 수를 순서대로 출력한다.



## 아이디어
두 개의 우선순위 큐를 정의하되, 하나는 오름차순, 하나는 내림차순으로 정렬한다. 그러면 두 큐에서 top은 항상 중앙값에 인접한 수들만 존재한다. top에 적힌 수와 입력되는 수를 비교할 수 있으므로 1차 분류를 하고, 개수의 불균형이 생기지 않도록 각 큐에서 빼서 옮기는 방식으로 이동시킨다.

```cpp
//  define min/max heap pq
//  for all inputs
//      if start or 
//          push to min heap
//      else
//          push to max heap
//      if min heap size > max heap size + 1
//          pick top from min heap and push it to max heap
//      else if min heap size < max heap size
//          pick top from max heap and push it to min heap
```

## 최종

```cpp
#include <bits/stdc++.h>
#define DEBUG
using namespace std;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n;
    cin >> n;

    priority_queue<int, vector<int>, less<int>> min_pq;
    priority_queue<int, vector<int>, greater<int>> max_pq;

    while(n--) {
        int val;
        cin >> val;
        if(min_pq.empty() || min_pq.top() >= val) {
            min_pq.push(val);
        } else {
            max_pq.push(val);
        }
        if(min_pq.size() < max_pq.size()) {
            min_pq.push(max_pq.top());
            max_pq.pop();
        }
        else if(min_pq.size() > max_pq.size() + 1) {
            max_pq.push(min_pq.top());
            min_pq.pop();
        }
        cout << min_pq.top() << "\n";
    }


    return 0;
}
```
