## 문제
은하는 긴 막대에 
$N$개의 과일이 꽂혀있는 과일 탕후루를 만들었습니다. 과일의 각 종류에는 
$1$부터 
$9$까지의 번호가 붙어있고, 앞쪽부터 차례로 
$S_1, S_2, \cdots, S_N$번 과일이 꽂혀있습니다. 과일 탕후루를 다 만든 은하가 주문을 다시 확인해보니 과일을 두 종류 이하로 사용해달라는 요청이 있었습니다.

탕후루를 다시 만들 시간이 없었던 은하는, 막대의 앞쪽과 뒤쪽에서 몇 개의 과일을 빼서 두 종류 이하의 과일만 남기기로 했습니다. 앞에서 
$a$개, 뒤에서 
$b$개의 과일을 빼면 
$S_{a+1}, S_{a+2}, \cdots, S_{N-b-1}, S_{N-b}$번 과일, 총 
$N-(a+b)$개가 꽂혀있는 탕후루가 됩니다. 
$(0 \le a, b;$ 
$a+b < N)$ 

이렇게 만들 수 있는 과일을 두 종류 이하로 사용한 탕후루 중에서, 과일의 개수가 가장 많은 탕후루의 과일 개수를 구하세요.

## 아이디어

처음에는 dp로 풀려고 했었다.

```cpp
// table[i][j] which check number with bitmask idx i to j
// first, put bitmask to table[i][i](len 1)
// next, put (bit calculate result) to length k+1 from two length k result
```

그런데 이렇게 풀면 $200,000^2$의 memory order를 갖기 때문에 메모리 초과가 뜰 것이고 시간도 문제였다.

알고리즘 힌트를 받고 브루트포스를 하되, 포인터를 이용한다. 핵심 아이디어는 어떤 (start, end) 인덱스 범위가 조건을 만족하면, 그 안에 포함되는 모든 인덱스 범위도 조건을 만족하게 된다. 그러면 굳이 $N^2$로 반복할 필요 없이 곧바로 sliding window 시키면 된다. 그러면 $N$으로 끝낼 수 있다.

```cpp
//  max_len = 0, num_lastidx[]
//  (start, end) at (0,0)
//  while start pointer is end:
//      check input[end] already counts
//      if not counted:
//          add idx to num_lastidx[]
//          if (num_lastidx[] counting) > 3:
//              move start until (num_lastidx[] counting <= 2)
//      increment end pointer
```

## Brute Force with Pointers
```cpp
#include <bits/stdc++.h>

using namespace std;

int count(vector<int> &v) {
    int cnt = 0;
    for(int i = 0; i < v.size(); i++) {
        if(v[i] != -1) cnt++;
    }
    return cnt;
}

int main() {
    int N;
    cin >> N;
    vector<int> v(N);
    for(int i = 0; i < N; i++) {
        int val;
        cin >> val;
        v[i] = val;
    }

    int max_len = 1;
    vector<int> num_lastidx(10, -1);
    int l_ptr = 0, r_ptr = 0;
    while(r_ptr < N) {
        num_lastidx[v[r_ptr]] = r_ptr;
        while(count(num_lastidx) > 2) {
            num_lastidx[v[l_ptr]] = (num_lastidx[v[l_ptr]] == l_ptr) ? -1 : num_lastidx[v[l_ptr]];
            l_ptr++;
        }
        max_len = max(max_len, r_ptr - l_ptr + 1);
        r_ptr++;
    }

    cout << max_len;

    return 0;
}
```

```
7 5 5 2 4 2 2 5 5 5
```
같은 숫자가 연속해서 나오는 이런 반례에 대응하지 못하기 때문에 시간을 많이 끌었다.
