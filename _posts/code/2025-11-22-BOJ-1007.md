## 문제

평면 상에 N개의 점이 찍혀있고, 그 점을 집합 P라고 하자. 집합 P의 벡터 매칭은 벡터의 집합인데, 모든 벡터는 집합 P의 한 점에서 시작해서, 또 다른 점에서 끝나는 벡터의 집합이다. 또, P에 속하는 모든 점은 한 번씩 쓰여야 한다.

벡터 매칭에 있는 벡터의 개수는 P에 있는 점의 절반이다.

평면 상의 점이 주어졌을 때, 집합 P의 벡터 매칭에 있는 벡터의 합의 길이의 최솟값을 출력하는 프로그램을 작성하시오.

## 아이디어

두 점이 있을 때 벡터는

$$
\vec{AB}=B-A
$$

로 표현된다. 그러니까 모든 포인트가 벡터로 연결된다면 절반은 +, 절반은 -인 상태이다. 이 점에서 착안하여,

$N$개의 점이 주어졌을 때, $\frac{N}{2}$의 부호는 그대로, 나머지는 반전하여 element-wise로 summation하면 벡터 매칭의 합이 구해진다.

그러면 이제 문제는 $_NC_{\frac{N}{2}}$의 모든 경우의 수를 구해야 하는데, 고민하다가 모르겠어서 AI에게 물어보았다.

백트래킹으로 정할 수 있다고 한다. 나는 재귀 함수를 보면 불안해지는 병이 있어 스택으로 할 수는 없을까 고민했는데, state history를 노드마다 넣어주기에는 메모리를 너무 낭비하는 것 같아 별로였다. 마침 이럴 때 효과적으로 사용할 수 있는 비트마스킹이 떠올라 관련 코드도 작성해보았다.

## 백트래킹
```cpp
#include <bits/stdc++.h>

using namespace std;

double calculate(vector<vector<double>> &pt, vector<int> &visit) {
    double sum_x = 0;
    double sum_y = 0;
    double value;

    for(int j = 0; j < pt.size(); j++) {
        int coef = visit[j] ? 1 : -1;
        sum_x += coef * pt[j][0];
        sum_y += coef * pt[j][1];
    }
    return sqrt(pow(sum_x ,2) + pow(sum_y, 2));
}

void dfs(int cur, int depth, int N, vector<int> &visit, vector<vector<double>> &pt, double &v_min) {
    if(depth == N/2) {
        v_min = min(v_min, calculate(pt, visit));
    }
    else {
        for (int j = cur + 1; j < N; j++) {
            visit[j] = 1;
            dfs(j, depth + 1, N, visit, pt, v_min);
            visit[j] = 0;
        }
    }
}

int main() {
    int T;
    cin >> T;
    for(int i = 0; i < T; i++) {
        int N;
        cin >> N;
        vector<vector<double>> pt(N, vector<double>(2));
        double v_min = DBL_MAX;
        vector<int> visit(N, 0);
        for(int j = 0; j < N; j++) {
            int x, y;
            cin >> x >> y;
            pt[j][0] = x;
            pt[j][1] = y;
        }
        
        dfs(-1, 0, N, visit, pt, v_min);
        
        cout << fixed << setprecision(12) << v_min << "\n";
    }


    return 0;
}
```

## 비트마스킹
```cpp
#include <bits/stdc++.h>

using namespace std;

double calculate(vector<vector<double>> &pt, int hist) {
    double sum_x = 0;
    double sum_y = 0;
    double value;

    for(int j = 0; j < pt.size(); j++) {
        int coef = ((hist >> j) % 2 == 1) ? 1 : -1;
        sum_x += coef * pt[j][0];
        sum_y += coef * pt[j][1];
    }
    return sqrt(pow(sum_x ,2) + pow(sum_y, 2));
}

int main() {
    int T;
    cin >> T;
    for(int i = 0; i < T; i++) {
        int N;
        cin >> N;
        vector<vector<double>> pt(N, vector<double>(2));
        double v_min = DBL_MAX;
        for(int j = 0; j < N; j++) {
            int x, y;
            cin >> x >> y;
            pt[j][0] = x;
            pt[j][1] = y;
        }

        stack<tuple<int, int>> s;
        s.push(make_tuple(-1, 0));
        while(!s.empty()) {
            int cur, hist;
            tie(cur, hist) = s.top();
            s.pop();

            int depth;
            if((depth = __builtin_popcount(hist)) == N / 2) {
                v_min = min(v_min, calculate(pt, hist));
            }
            else {
                for(int j = cur + 1; j < N; j++) {
                    s.push(make_tuple(j, hist | (1 << j)));
                }
            }
        }
        cout << setprecision(12) << fixed << v_min << "\n";
    }


    return 0;
}
```
여담으로, 처음에 ```pow(2, j)```를 사용하여 상태를 업데이트하려 했는데 그러면 반환되는 ```double``` 값이 ```int```로 캐스팅되면서 문제가 생길 수 있다고 한다. 그래서 ```(1 << j)```를 쓰는 것이 권장. 정답과는 무관함.

그리고 ```setprecision()```, ```fixed```를 '올바른 위치'에 사용해서 소수점 정확도를 일관되게 유지하자... 이것때문에 많은 시간을 소비했다.
