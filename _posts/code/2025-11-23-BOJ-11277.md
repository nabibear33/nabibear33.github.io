## 문제
2-SAT은 N개의 불리언 변수
$x_1, x_2, ..., x_n$가 있을 때, 2-CNF 식을 true로 만들기위해
$x_i$를 어떤 값으로 정해야하는지를 구하는 문제이다.

2-CNF식은
$ \left( x \lor y \right) \land \left( \lnot y \lor z \right) \land \left( x \lor \lnot z \right) \land \left( z \lor y \right) $ 와 같은 형태이다. 여기서 괄호로 묶인 식을 절(clause)라고 하는데, 절은 2개의 변수를
$\lor$한 것으로 이루어져 있다.
$\lor$는 OR,
$\land$는 AND,
$\lnot$은 NOT을 나타낸다.

변수의 개수 N과 절의 개수 M, 그리고 식
$f$가 주어졌을 때, 식
$f$를 true로 만들 수 있는지 없는지를 구하는 프로그램을 작성하시오.

예를 들어, N = 3, M = 4이고,
$f =  \left( \lnot x_1 \lor x_2 \right) \land \left( \lnot x_2 \lor x_3 \right) \land \left( x_1 \lor x_3 \right) \land \left( x_3 \lor x_2 \right) $ 인 경우에
$x_1$을 false,
$x_2$을 false,
$x_3$를 true로 정하면 식
$f$를 true로 만들 수 있다. 하지만, N = 1, M = 2이고,
$f = \left( x_1 \lor x_1 \right) \land \left( \lnot x_1 \lor \lnot x_1 \right) $인 경우에는
$x_1$에 어떤 값을 넣어도 식 f를 true로 만들 수 없다.

## 아이디어

예전에 SCC로 이걸 푼다는 것을 보았기 때문에 실버 1에서는 SCC로 풀 이유는 없을 거라는 생각을 했다. 그래서 변수 개수를 보니 브루트 포스로 풀 수 있을 것 같아서 그렇게 작성했다. 참 거짓으로만 state가 정해지기 때문에 비스마스킹을 이용하였다.

## Brute Force
```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
    int n, m;
    cin >> n >> m;

    vector<vector<int>> v(m, vector<int>(2));

    for(int i = 0; i < m; i++) {
        for(int j = 0; j < 2; j++) {
            int a;
            cin >> a;
            v[i][j] = a;
        }
    }

    long long bitmask = 0;
    while(bitmask < pow(2, n)) {
        for(int i = 0; i < m; i++) {
            int a = v[i][0];
            int b = v[i][1];
            bool is_a_true = (a > 0) ? ((bitmask >> (abs(a) - 1)) & 1) : !((bitmask >> (abs(a) - 1)) & 1);
            bool is_b_true = (b > 0) ? ((bitmask >> (abs(b) - 1)) & 1) : !((bitmask >> (abs(b) - 1)) & 1);
            bool is_cnf_true = is_a_true || is_b_true;
            if(!is_cnf_true) {
                break;
            }
            if(i == m - 1) {
                cout << 1;
                return 0;
            }
        }
        bitmask++;
    }
    cout << 0;

    return 0;
}
```

## AI Code Refinement

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    vector<pair<int, int>> clauses(m);
    for(int i = 0; i < m; i++) {
        cin >> clauses[i].first >> clauses[i].second;
    }
    
    // 모든 가능한 변수 할당 시도
    for(int mask = 0; mask < (1 << n); mask++) {
        bool satisfied = true;
        
        for(auto [a, b] : clauses) {
            // 변수의 진리값 확인
            bool val_a = (mask >> (abs(a) - 1)) & 1;
            bool val_b = (mask >> (abs(b) - 1)) & 1;
            
            // 리터럴의 진리값 (음수면 NOT)
            bool lit_a = (a > 0) ? val_a : !val_a;
            bool lit_b = (b > 0) ? val_b : !val_b;
            
            // OR 절이 false면 전체 CNF가 false
            if(!(lit_a || lit_b)) {
                satisfied = false;
                break;
            }
        }
        
        if(satisfied) {
            cout << 1;
            return 0;
        }
    }
    
    cout << 0;
    return 0;
}
```
