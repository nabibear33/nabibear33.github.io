## 문제
준영이는 매일 서울에서 포천까지 출퇴근을 한다. 하지만 잠이 많은 준영이는 늦잠을 자 포천에 늦게 도착하기 일쑤다. 돈이 많은 준영이는 고민 끝에 K개의 도로를 포장하여 서울에서 포천까지 가는 시간을 단축하려 한다.

문제는 N개의 도시가 주어지고 그 사이 도로와 이 도로를 통과할 때 걸리는 시간이 주어졌을 때 최소 시간이 걸리도록 하는 K개의 이하의 도로를 포장하는 것이다. 도로는 이미 있는 도로만 포장할 수 있고, 포장하게 되면 도로를 지나는데 걸리는 시간이 0이 된다. 또한 편의상 서울은 1번 도시, 포천은 N번 도시라 하고 1번에서 N번까지 항상 갈 수 있는 데이터만 주어진다.

첫 줄에는 도시의 수 N(1 ≤ N ≤ 10,000)과 도로의 수 M(1 ≤ M ≤ 50,000)과 포장할 도로의 수 K(1 ≤ K ≤ 20)가 공백으로 구분되어 주어진다. M개의 줄에 대해 도로가 연결하는 두 도시와 도로를 통과하는데 걸리는 시간이 주어진다. 도로들은 양방향 도로이며, 걸리는 시간은 1,000,000보다 작거나 같은 자연수이다.

첫 줄에 K개 이하의 도로를 포장하여 얻을 수 있는 최소 시간을 출력한다.



## 아이디어
Claude에게 물어물어 가며 겨우 풀었다. 기존 다익스트라로는 출발점 기준의 1차원 dp를 풀게 된다. 핵심 아이디어는 dp의 차원을 2차원으로 늘리는 것이다. 한 차원은 여전히 도착지를 의미하고 다른 차원은 제거한 edge의 개수로 둘 수 있다. 기존에는 우회로의 cost가 적은 경우에 dp array를 채웠다. 하지만 이번 문제에서는 또 다른 옵션, edge를 제거하고(카운팅하고) dp table을 채울 수 있기도 하다. 따라서 루프 내에 두 개의 push 옵션을 갖게 된다.

참고로 dp의 두번째 인덱스는 정확히 k개 제거한 경우 중 최소를 의미하는데 그렇기 때문에 단조감소하지 않는다.
```
S --1-- T    (최단 경로: 거리 1, edge 0개 사용)

그런데 "정확히 2개 사용"으로 가려면?
S → 어딘가 → 어딘가 → T  (무의미한 우회)
```
따라서 도착지 기준으로 k에 대한 minimum을 취해 주어야 한다.


## 최종

```cpp
#include <bits/stdc++.h>
// #define DEBUG 
using namespace std;


struct Edge {
    int dest;
    int cost;
};


struct State {
    long long dist;
    int count;
    int city;
};


struct Compare {
    bool operator()(const State &a, const State &b) const {
        if(a.dist == b.dist) {
            if(a.count == b.count) return a.city > b.city;
            else return a.count > b.count;
        }
        return a.dist > b.dist;
    }
};


class Graph {
    private:
    vector<vector<Edge>> adj;
    vector<vector<long long>> dist;
    int n, k;
    
    public:
    Graph(vector<vector<Edge>> adj_, int k_);
    void simulate();
    
};


Graph::Graph(vector<vector<Edge>> adj_, int k_) : adj(adj_), k(k_) {
    n = adj.size() - 1;
    dist = vector<vector<long long>>(n + 1, vector<long long>(k + 1, LONG_LONG_MAX));
    for(int i = 0; i <= k; i++) {
        dist[1][i] = 0;
    }
}


void Graph::simulate() {
    priority_queue<State, vector<State>, Compare> pq;
    pq.push({0, 0, 1});
    
    while(!pq.empty()) {
        State current = pq.top();
        pq.pop();
    
        if(dist[current.city][current.count] < current.dist) {
            continue;
        }
        
        for(auto &[next_city, cost_to_go]: adj[current.city]) {
            if(dist[next_city][current.count] > dist[current.city][current.count] + cost_to_go) {
                dist[next_city][current.count] = dist[current.city][current.count] + cost_to_go;
                pq.push({dist[next_city][current.count], current.count, next_city});
            }
            if(current.count < k && dist[next_city][current.count + 1] > dist[current.city][current.count]) {
                dist[next_city][current.count + 1] = dist[current.city][current.count];
                pq.push({dist[next_city][current.count + 1], current.count + 1, next_city});
            }
        }
    }

    cout << *min_element(dist[n].begin(), dist[n].end());
}


int main() {
    int n, m, k;
    cin >> n >> m >> k;

    vector<vector<Edge>> adj(n + 1);
    while(m--) {
        int u, v, c;
        cin >> u >> v >> c;
        adj[u].push_back({v, c});
        adj[v].push_back({u, c});
    }
    
    Graph g(adj, k);
    g.simulate();

}

```
