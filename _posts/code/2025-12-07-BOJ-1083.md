## 문제
크기가 N인 배열 A가 있다. 배열에 있는 모든 수는 서로 다르다. 이 배열을 소트할 때, 연속된 두 개의 원소만 교환할 수 있다. 그리고, 교환은 많아봐야 S번 할 수 있다. 이때, 소트한 결과가 사전순으로 가장 뒷서는 것을 출력한다.

## 아이디어
아이디어가 떠오르지 않아 알고리즘 힌트를 보았고, 그리디 알고리즘으로 문제를 풀었다. 사전 순 나열은 가장 앞 요소가 중요하기 때문에 앞 인덱스부터 시작하였다. 남은 이동 횟수가 충분하면 전체 리스트 요소를 다 비교하면 되지만, 그렇지 않는 경우도 있기 때문에 둘 중 작은 값을 기준으로 비교하였다. 비교 대상 중 가장 큰 값을 맨 앞으로 당겨오고, 그 사이에 있는 요소들은 한 칸씩 뒤로 밀리게 된다.

```cpp
//  start at first index
//  while left move count is over zero and index is not end
//      get maximum index at range
//      pull the value to the current index
//      shift the values between the current/maximum index
```

## Code
```cpp
#include <bits/stdc++.h>
// #define DEBUG 
using namespace std;


int main() {
    int N;
    cin >> N;
    vector<int> v(N);
    for(int i = 0; i < N; i++) {
        cin >> v[i];
    }
    
    int left;
    cin >> left;

    int current_idx = 0;
    while(left > 0 && current_idx < N - 1) {
        int range = min(left, N - 1 - current_idx);
        int max_idx = max_element(v.begin() + current_idx, v.begin() + current_idx + range + 1) - v.begin();
        int temp = *(v.begin() + max_idx);
        for(int i = max_idx; i > current_idx; i--) {
            v[i] = v[i - 1];
        }
        v[current_idx] = temp;
        left -= max_idx - current_idx;
        current_idx++;
    }

    for(int x : v) {
        cout << x << " ";
    }
    return 0;
}

```

## 추가
인접 요소끼리 바꾸는 과정을 단순화하기 위해 swap(a, b)를 처음에 사용했는데 이건 잘못된 사용이다. 중간 값들을 한 칸씩 밀어야 한다.


rotate를 사용하여 코드를 단순화시킬 수 있다.
```cpp
// current ~ max_idx - 1 구간과 max_idx ~ max_dix 구간을 switch
rotate(v.begin() + current, v.begin() + max_idx, v.begin() + max_idx + 1);
```
