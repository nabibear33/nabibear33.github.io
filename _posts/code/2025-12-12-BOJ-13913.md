## 문제 한줄요약

bfs with 1-d state sequence의 문제는 이전 값, cost를 저장하는 vector를 활용하여 풀 수 있다.


## 문제
수빈이는 동생과 숨바꼭질을 하고 있다. 수빈이는 현재 점 N(0 ≤ N ≤ 100,000)에 있고, 동생은 점 K(0 ≤ K ≤ 100,000)에 있다. 수빈이는 걷거나 순간이동을 할 수 있다. 만약, 수빈이의 위치가 X일 때 걷는다면 1초 후에 X-1 또는 X+1로 이동하게 된다. 순간이동을 하는 경우에는 1초 후에 2*X의 위치로 이동하게 된다.

수빈이와 동생의 위치가 주어졌을 때, 수빈이가 동생을 찾을 수 있는 가장 빠른 시간이 몇 초 후인지 구하는 프로그램을 작성하시오.

첫 번째 줄에 수빈이가 있는 위치 N과 동생이 있는 위치 K가 주어진다. N과 K는 정수이다.

첫째 줄에 수빈이가 동생을 찾는 가장 빠른 시간을 출력한다.

둘째 줄에 어떻게 이동해야 하는지 공백으로 구분해 출력한다.




## 아이디어
BFS로 풀면 좋을 것 같았는데, 문제는 경로를 tracking 해야 한다는 부분이다. 모든 경로를 queue에 집어넣기에는 메모리 이슈가 있어서 ai에게 물어보아 해결하였다. 상태가 1차원 숫자이기 때문에 배열에 이전 상태를 담는 방식으로 활용할 수 있다. 값을 찾으면 역방향으로 부모의 요소를 재귀적으로 얻어갈 수 있다.


## 최종

```cpp
#include <bits/stdc++.h>
// #define DEBUG 
using namespace std;


struct Edge {
    int dest;
    int cost;
};


struct State {
    long long dist;
    int count;
    int city;
};


struct Compare {
    bool operator()(const State &a, const State &b) const {
        if(a.dist == b.dist) {
            if(a.count == b.count) return a.city > b.city;
            else return a.count > b.count;
        }
        return a.dist > b.dist;
    }
};


class Graph {
    private:
    vector<vector<Edge>> adj;
    vector<vector<long long>> dist;
    int n, k;
    
    public:
    Graph(vector<vector<Edge>> adj_, int k_);
    void simulate();
    
};


Graph::Graph(vector<vector<Edge>> adj_, int k_) : adj(adj_), k(k_) {
    n = adj.size() - 1;
    dist = vector<vector<long long>>(n + 1, vector<long long>(k + 1, LONG_LONG_MAX));
    for(int i = 0; i <= k; i++) {
        dist[1][i] = 0;
    }
}


void Graph::simulate() {
    priority_queue<State, vector<State>, Compare> pq;
    pq.push({0, 0, 1});
    
    while(!pq.empty()) {
        State current = pq.top();
        pq.pop();
    
        if(dist[current.city][current.count] < current.dist) {
            continue;
        }
        
        for(auto &[next_city, cost_to_go]: adj[current.city]) {
            if(dist[next_city][current.count] > dist[current.city][current.count] + cost_to_go) {
                dist[next_city][current.count] = dist[current.city][current.count] + cost_to_go;
                pq.push({dist[next_city][current.count], current.count, next_city});
            }
            if(current.count < k && dist[next_city][current.count + 1] > dist[current.city][current.count]) {
                dist[next_city][current.count + 1] = dist[current.city][current.count];
                pq.push({dist[next_city][current.count + 1], current.count + 1, next_city});
            }
        }
    }

    cout << *min_element(dist[n].begin(), dist[n].end());
}


int main() {
    int n, m, k;
    cin >> n >> m >> k;

    vector<vector<Edge>> adj(n + 1);
    while(m--) {
        int u, v, c;
        cin >> u >> v >> c;
        adj[u].push_back({v, c});
        adj[v].push_back({u, c});
    }
    
    Graph g(adj, k);
    g.simulate();

}

```
