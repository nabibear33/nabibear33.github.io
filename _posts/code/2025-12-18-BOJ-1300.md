## 문제 한줄요약
이분 탐색인데 x가 아닌 A[x]에 대한 이분 탐색이라 신기했다.



## 문제
세준이는 크기가 N×N인 배열 A를 만들었다. 배열에 들어있는 수 A[i][j] = i×j 이다. 이 수를 일차원 배열 B에 넣으면 B의 크기는 N×N이 된다. B를 오름차순 정렬했을 때, B[k]를 구해보자.

배열 A와 B의 인덱스는 1부터 시작한다.

첫째 줄에 배열의 크기 N이 주어진다. N은 105보다 작거나 같은 자연수이다. 둘째 줄에 k가 주어진다. k는 min(10^9, N2)보다 작거나 같은 자연수이다.

B[k]를 출력한다.


## 아이디어
배열의 사이즈가 크기 때문에 배열을 정렬하거나 생성하는 것조차 불가능하다. 값을 직접 비교하지 않고 대소를 확인하는 방법으로 몫을 이용하여 카운트를 누적합 시키는 방법을 사용한다. 각 행이 등차수열이니까 가능하게 된다. 참신한 아이디어라고 생각했다. 그러면 N번 반복으로도 숫자 x에 대해 x이하인 개수를 구할 수 있다.

조건을 구했으니 이제 이분 탐색을 진행한다. 파라미터는 x로 문제에서는 B[k]와 대응되는 값이다.

## 최종

```cpp
#include <bits/stdc++.h>
// #define DEBUG 
using namespace std;


int main() {
    ios::sync_with_stdio(0); cin.tie(0);

    int n, k;
    cin >> n >> k;

    long long l = 1;
    long long r = min(pow(10, 9), (double)n * n);

    while(l < r) {
        long long mid = (l + r) / 2;
        int count = 0;
        for(int i = 1; i <= n; i++) {
            count += min(n, (int)(mid / i)); // leq mid
        }
        if(count < k) {
            l = mid + 1;
        } else {
            r = mid;
        }
    }

    cout << l;
}
```
